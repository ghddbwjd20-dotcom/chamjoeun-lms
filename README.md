# 참조은다문화 LMS UI 시안

계약서(온라인 교육 통합 홈페이지 구축)의 **LMS · 회원 · 결제 · 관리자** 화면만 따로 모은 UI/UX 시안입니다. 서버, PG, 알림톡은 연결하지 않았습니다.

기관 소개와 법무부 사업은 기존 홈페이지에 두고, 이 저장소는 학습 공간만 담당합니다.

- 기관 홈페이지: https://ghddbwjd20-dotcom.github.io/chamjoeun-multiculture/v4/
- 이 강의실 시안: GitHub Pages로 올리면 `/` 가 입구입니다.

## 홈페이지와 연결

1. 방문자는 먼저 v4 메인에서 기관 성격을 봅니다.  
   “외국인의 안정적인 정착과 교육을 지원하는 전문기관”
2. 동포체류지원센터, 사회통합(KIIP), 조기적응은 **홈페이지**에 남깁니다.  
   KIIP 신청은 사회통합정보망입니다.
3. 사업 소개 다음, 교육과정 페이지에서 **강의실 입장**으로 이 시안으로 옵니다.
4. 가입 → 과정 신청(무료/유료) → 나의 강의실 → 수료증.

| 홈페이지에 남김 | 이 LMS에서 함 |
|---|---|
| 기업소개, 소식, 문의 | 회원가입 · 로그인 · 소셜(시안) |
| 동포체류, KIIP, 조기적응 | 한국어 · 자격 · 평생교육 수강 |
| 사업 안내 | 결제, 진도, 이어보기, 수료 |
| 오시는 길 | 수료증 · 자격증, 관리자 |

## 계약 범위와 이 시안

별첨 1 기준으로 화면만 구성했습니다.

- 회원: 가입, 로그인, 찾기, 소셜 버튼
- 과정: 목록, 상세, 무료/유료, 커리큘럼, 신청
- 결제: 카드결제 자리(시안)
- LMS: 내 강의실, 다중 차시, 영상, 진도 90% 수료
- 마이페이지 · 발급문서
- 관리자: 회원/과정/진도/결제/문서/공지/알림

제외(계약과 동일): 시험·퀴즈, 실시간 화상, 쿠폰, 앱, 다국어.
